# DAC-web3

Building a community-focused Web3 ecosystem for identity, communication, and participation.

## DACx — Android 1.5.11

DACx is the ecosystem's ephemeral messaging app with an on-device Solana Devnet wallet. The latest Android release adds:

- **Device-protected biometric wallet unlock**, with the PIN available as a fallback.
- **Wallet recovery on a new phone** using the recovery phrase and a new PIN.
- **Safer local wallet-data migration**, preserving the original encrypted data until the updated data is written and verified.

**[Download the official DACx 1.5.11 APK](https://github.com/DAC-web3/dacx/releases/download/v1.5.11/dacx-1.5.11.apk)** · [Release notes](https://github.com/DAC-web3/dacx/releases/tag/v1.5.11) · [DACx project](https://github.com/DAC-web3/dacx)

**Recovery phrase safety:** Keep your phrase private. Never share it, including with support; enter it only in the official app when starting wallet recovery.

DACx chat messages are **not end-to-end encrypted**. See the [public project README](https://github.com/DAC-web3/dacx#privacy-commitment) for the product's privacy details.
